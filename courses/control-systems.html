MODULE 1

On-Off (Bang-Bang) Control

The simplest controller: the actuator is either fully ON or fully OFF, like a thermostat. To stop it switching infinitely fast, we add a hysteresis band around the setpoint — turn ON below the band, OFF above it. The output never settles exactly; it oscillates within the band. Wider band → slower switching but bigger ripple.

OutputSetpointHeater ON/OFF
💡 Try: shrink the band to 1 — see the rapid "chattering". Widen it to 20 — bigger ripple, fewer switches. That trade-off is the whole story of on-off control.
MODULE 2

PID Control

P reacts to the present error, I erases steady-state error by accumulating the past, and D anticipates the future by reacting to the rate of change. Tune them on an underdamped plant and watch the step response. Too much P → oscillation; too much I → overshoot & sluggish settling; D → damping (but noise-sensitive).

ResponseSetpoint
💡 Try: start with only Kp=4 (note the steady-state gap). Add Ki=1 to close the gap. Then add Kd=0.3 to tame the overshoot. That's manual PID tuning.
MODULE 3

Bode Plot

A Bode plot shows how a system responds to each frequency: magnitude (gain, in dB) and phase (lag, in degrees) versus frequency on a log scale. For a 2nd-order system, low damping ζ creates a resonant peak near ωn. The plot below is for G(s) = K·ωn²/(s² + 2ζωns + ωn²).

💡 Try: drop ζ to 0.05 — a sharp resonant peak appears in the magnitude plot. Raise ζ above 0.7 — the peak disappears (well-damped).
MODULE 4

Polar / Nyquist Plot

The same frequency response, drawn in the complex plane: each point is G(jω) as ω sweeps from 0 → ∞. This is the basis of the Nyquist stability criterion — how close the curve passes to the critical point −1 tells you the stability margins. Same G(s) as the Bode module.

G(jω)−1 point
💡 Try: increase K and watch the curve swell toward the −1 point — that's the system marching toward instability.
MODULE 5

Routh-Hurwitz Array

Is a system stable without finding the roots? The Routh array answers it from the characteristic-polynomial coefficients alone. Build the table; the number of sign changes in the first column equals the number of unstable (right-half-plane) roots. Zero sign changes → stable.

Example: 1 2 3 4 5 means s⁴+2s³+3s²+4s+5.
💡 Try: 1 1 2 24 1 (unstable — sign changes). Then 1 6 11 6 (stable). Edit and watch the verdict flip.
MODULE 6

Root Locus

As loop gain K increases from 0 → ∞, where do the closed-loop poles go? The root locus traces those paths. Loci start at open-loop poles (×) and end at zeros (○) or infinity. When a branch crosses into the right-half-plane, the system goes unstable. Enter open-loop poles/zeros (real or a+bj), comma-separated.

locus× poles○ zerospoles at K
💡 Try the classic 0, -2, -4: raise K and watch two branches bend toward the right-half-plane and cross the imaginary axis — that gain is the stability limit.
